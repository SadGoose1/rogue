# Rogue

A Godot 4.6 C# 2D platformer roguelike with turn-based combat (Persona/FF style). Built in Godot 4.6.2 with .NET 8.

## Features
- 7 character classes (Knight, Mage, Rogue, Paladin, Ranger, Berserker, Gunslinger)
- 8-city world map with branching progression
- 46 unique skills with pierce, execute, self-damage, buff/debuff mechanics
- Turn-based combat with weakness system
- Procedural rooms with main and secret bosses per city
- Full loot/equipment system (3 slots, 5 rarities)
- Controller support
